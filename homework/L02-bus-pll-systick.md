| AHB1 | GPIO，USB，DMA1、2 |

## C. 实验（15 分钟，改代码 + 看现象）

**C1 降频实验**
把 `02-systick/src/main.c` 里 `PLLN` 从 336 改成 168（SYSCLK 变 84 MHz），重新烧录。

- 预期：LED 周期**仍然约 1 秒**（因为 `SystemCoreClock` 跟着更新了）。
- 如果你量到 2 秒，说明什么？（提示：`SystemCoreClock` 没更新，或 PLL 没真正切换）

**C2 中断里干重活**
在 `SysTick_Handler` 里加一句：

```c
for (volatile int i = 0; i < 500000; i++) { }
```

重新烧录，量周期。回答：

- 周期变成多少？
- 为什么不是简单的「1 秒 + 固定偏移」？
- 这验证了 L02 里的哪条结论？

**C3（挑战，可选）**
用内核的 `DWT->CYCCNT` 测 `delay_ms(100)` 实际花了多少个 CPU 周期，验证是否等于 `16800000`。

```c
CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;
DWT->CYCCNT = 0;
DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;
```
