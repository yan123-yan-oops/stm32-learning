# 01-key-led —— 按键控制 LED

对应课时：[L03 按键消抖与状态机](../lessons/L03-key-fsm.md)（这是**最初版本**，用阻塞延时消抖；正式版在 `03-key-fsm`）。

## 这个工程是干什么的

- 学会把按键配置成**输入 + 上拉**；
- 用 `IDR` 读取电平，按下为低；
- 用阻塞延时做消抖（**有缺陷**，L03 会改掉）。

## 硬件

- LED：PC13，低电平亮
- 按键：PA15、PE6，10K 上拉，按下为低；代码里两个都检测

## 运行

1. 打开本文件夹（含 `platformio.ini` 的那一层）；
2. Build → Upload；
3. 按任一个按键，灯应亮灭切换。

## 现象与问题

能工作，但存在三个问题（L03 会逐一解决）：

1. 消抖延时靠猜，主频一变就失效；
2. 消抖期间 CPU 阻塞，灯没法同时闪；
3. 写不了长按、双击这类逻辑。
