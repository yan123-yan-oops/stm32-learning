# L01 · GPIO 点灯与 BSRR 位操作

> 日期：2026-11-01 ｜ 目标：看懂「开时钟 → 配模式 → 写 BSRR」这条链路。

## 今天解决了什么

- PC13 绿灯点亮并闪烁；
- 理解了 GPIO 四个寄存器各自管什么；
- 第一次用秒表量周期：**3 个周期 65 秒 → 21.7 s/周期**，由此发现主频不对。

## 关键概念

GPIO 输出四步（少一步都不亮）：

```c
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;        // 1. 开时钟
GPIOC->MODER   |= (1u << (13*2));            // 2. 通用输出
GPIOC->OTYPER  &= ~(1u << 13);               // 3. 推挽
GPIOC->OSPEEDR &= ~(3u << (13*2));           // 4. 速度（PC13 上限 2 MHz）
GPIOC->PUPDR   &= ~(3u << (13*2));           //    无上下拉
```

**为什么用 BSRR 不用 ODR**：

| 写法 | 动作 | 风险 |
| --- | --- | --- |
| `ODR ^= (1<<n)` | 读-改-写三步 | 中断打断会丢状态 |
| `BSRR = (1<<n)` | 单次写，置位 | 原子操作，安全 |
| `BSRR = (1<<(n+16))` | 单次写，复位 | 同上 |

**PC13 的两个特殊性**：

1. 属于备份域（RTC 那组），驱动能力只有 **3 mA**、速度上限 **2 MHz**；
2. **低电平点亮**（例程 `led.h`：`LED1_ON = GPIOC->BRR`），所以写 0 是亮。

## 踩坑

- 延时用 `for (volatile uint32_t i=0; i<20000000; i++);`，结果 21.7 秒才闪一次。
  原因见 L02：主频其实是 16 MHz，不是 168 MHz。
- `volatile` 不能省：否则 `-O2` 下整个循环会被删掉。

## 自测三题

1. 不写 `RCC->AHB1ENR` 会怎样？为什么读回寄存器全是 0？
2. `BSRR` 的高低 16 位分别做什么？
3. 为什么这颗灯写 0 是亮、写 1 是灭？

<details><summary>参考答案</summary>

1. 外设没时钟就不响应写操作，配置不生效，灯不会亮。
2. 低 16 位置位（输出高），高 16 位复位（输出低）。
3. 硬件是共阳接法：LED 阳极接 3V3，阴极接 PC13，低电平形成回路。

</details>
